# Russian Passport Reader

Учебный Streamlit-прототип для извлечения данных из тестовых изображений внутренних и заграничных паспортов РФ.

## Поля
Фамилия, имя, отчество, пол, серия, номер, орган выдачи, код подразделения, дата выдачи, дата рождения; для загранпаспорта — дата окончания действия.

## Технологии
Python, Streamlit, EasyOCR, PyMuPDF, Pillow, NumPy

## Запуск
Переходим по ссылке: https://contract-data-extractor-gbmhymupmm6aubmdbaw9f2.streamlit.app
1. Нажимаем "Upload"
2. Выбираем наше фото в любом доступном виде
3. Нажимаем "Обработать изображение"
4. При необходимости скачиваем эксель файл с данными

## Ограничения
Для внутреннего паспорта режим распознавания по областям ориентирован на фотографию открытого разворота с расположением, похожим на тестовый образец. Для других ракурсов и форматов точность может снижаться. Загранпаспорт распознаётся по MRZ при успешном считывании. Результаты OCR обязательно проверяются вручную.

Это учебный прототип, не средство проверки подлинности. Не загружайте реальные паспорта в публичное приложение без надлежащих правовых оснований и мер защиты.
