# Распознавание данных из сканированных договоров

Веб-приложение на Python для распознавания текста в сканированных договорах и извлечения отдельных реквизитов.

## Возможности

- Загрузка одного или нескольких документов в форматах PDF, JPG и PNG.
- Распознавание русского и английского текста с помощью EasyOCR.
- Извлечение имени, фамилии, номера договора и контактного телефона.
- Группировка результатов в общую таблицу.
- Ручная проверка и редактирование результатов.
- Экспорт таблицы в CSV.

## Используемые технологии

- Python
- Streamlit — веб-интерфейс
- EasyOCR — нейросетевое распознавание текста
- PyMuPDF — преобразование страниц PDF в изображения
- Pandas — работа с таблицами

## Установка и запуск

1. Установите Python 3.10 или 3.11.
2. Скачайте проект.
3. Откройте терминал в папке проекта.
4. Установите зависимости:

```bash
pip install -r requirements.txt
```

5. Запустите веб-приложение:

```bash
streamlit run app.py
```

После запуска откроется веб-страница приложения в браузере.

## Принцип работы

1. Пользователь загружает скан договора.
2. PDF-страницы преобразуются в изображения.
3. EasyOCR распознаёт текст с помощью обученной нейросетевой модели.
4. Программа ищет значения нужных полей по текстовым меткам и шаблонам.
5. Результаты разных документов объединяются в таблицу.
6. Пользователь проверяет и при необходимости исправляет данные, затем скачивает CSV.

## Важные ограничения

Точность зависит от качества скана, языка и структуры договора. Если в договоре нет явных подписей полей (например, «Фамилия», «Имя», «Номер договора»), автоматическое извлечение может не сработать. Результаты необходимо проверять вручную.

Не загружайте реальные договоры с персональными данными в публичные демонстрационные сервисы без разрешения и надлежащих мер защиты. Для учебной демонстрации используйте обезличенные или вымышленные документы.
