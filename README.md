# Russian Passport Reader

Учебный веб-прототип для распознавания данных из внутренних и заграничных паспортов граждан РФ.

## Извлекаемые поля
- Фамилия, имя, отчество (если распознано)
- Орган, выдавший паспорт (если указан и распознан)
- Пол
- Серия и номер документа
- Дата выдачи
- Дата рождения
- Дата окончания действия / ориентировочный срок замены

## Технологии
- Python
- Streamlit
- EasyOCR (нейросетевое OCR)
- PyMuPDF
- Pandas

## Запуск
```bash
pip install -r requirements.txt
streamlit run app.py
```

При первом запуске EasyOCR может загрузить веса языковой модели. Требуется интернет-соединение.

## Важно
Это учебный прототип, не проверяет подлинность паспорта и не подходит для юридически значимых решений.
Для внутреннего паспорта РФ дата окончания не печатается: по общему правилу он действует до 20 лет, затем до 45 лет, после 45 лет — бессрочно. Программа показывает ориентировочный расчёт по дате рождения; он не учитывает все основания для замены документа.

Используйте только вымышленные или обезличенные тестовые документы. Не размещайте реальные паспортные данные в публичном приложении.
